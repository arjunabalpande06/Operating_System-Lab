# 🖥️ Operating System Lab

A collection of Operating System laboratory programs and practical implementations covering fundamental concepts of process management, CPU scheduling, memory management, file systems, and Linux commands.

## 📌 About the Repository

This repository contains practical implementations of Operating System concepts developed as part of the academic laboratory coursework.

The programs demonstrate how an operating system manages processes, allocates memory, handles files, and coordinates multiple processes through synchronization techniques.

The primary objective is to understand the working principles of operating systems through hands-on programming and experimentation.

## 🎯 Objectives

- Understand fundamental Operating System concepts.
- Explore Linux commands and shell scripting.
- Learn process creation and management.
- Implement CPU scheduling algorithms.
- Understand process synchronization.
- Study memory management techniques.
- Implement page replacement algorithms.
- Understand file allocation methods.
- Develop system-level programming skills.

## 📚 Concepts Covered

### 1. Linux Commands and Shell Scripting
- Basic Linux commands
- File and directory management
- Shell scripting
- Command-line arguments
- File permissions

### 2. Process Management
- Process creation
- Process termination
- Parent and child processes
- UNIX system calls
- Process execution

### 3. CPU Scheduling Algorithms
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Priority Scheduling
- Round Robin Scheduling

### 4. Process Synchronization
- Critical Section Problem
- Semaphores
- Producer-Consumer Problem
- Mutual Exclusion

### 5. Memory Management
- First Fit
- Best Fit
- Worst Fit
- Memory allocation techniques

### 6. Page Replacement Algorithms
- FIFO (First In First Out)
- LRU (Least Recently Used)
- Optimal Page Replacement

### 7. File Management
- File allocation techniques
- Sequential Allocation
- Linked Allocation
- Indexed Allocation

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- GCC Compiler
- Linux / Ubuntu or WSL
- Visual Studio Code (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/Operating_System-Lab.git
```

### 2. Navigate to the Project Directory

```bash
cd Operating_System-Lab
```

### 3. Compile a C Program

```bash
gcc filename.c -o output
```

### 4. Execute the Program

```bash
./output
```

### 5. Execute Shell Scripts

Give execution permission:

```bash
chmod +x filename.sh
```

Run the script:

```bash
./filename.sh
```

**Note:** Programs using POSIX threads may require the `-pthread` compiler option.
